# 성찬의 iPhone

『염치도 없이』 1~11화 속 정성찬의 핸드폰을 열어 볼 수 있는 웹페이지예요.
독자는 **11화, 6월 3일 새벽 1시 53분**의 핸드폰을 보게 돼요. 시계는 이 시각부터 실제로 흘러가요.

---

## 1. 독자가 보는 흐름

1. 링크를 열면 **김희수 인스타 DM 창**에서 시작해요. 입력창에 "너 지금 은석이랑 있"이 한 글자씩 써져요.
   - 다 써지기 전에는 수정할 수 없고, 다 써지면 독자가 지우거나 고칠 수 있어요. 보내기 버튼은 눌리지 않아요.
2. 다 써지고 1.2초 뒤부터 **🏀🏀 단톡방 알림**이 차례로 내려와요. (소희 → 소희 → 타로 → 소희 → 5초 뒤 은석)
   - 어느 알림을 눌러도 단톡방이 열리고, 남은 대화는 방 안에서 이어서 올라와요.
3. 화면 맨 아래 막대(홈 인디케이터)를 누르면 홈 화면으로 가요.

### 미션 (독자 이벤트)
아래 4가지를 순서 상관없이 하면 홈 화면 **지도 위젯**이 바뀌어요.

| 미션 | 인정 조건 |
|---|---|
| 인스타 댓글 | 얼라이브 게시글에 댓글 달기 |
| 에타 스크랩 | '스크랩한 글' 화면에 들어가기 |
| 스포티파이 | 앱 열기 |
| 캘린더 | 앱 열기 |

- 1개: 성찬 핀이 집 → 체육관 중간으로
- 2개: 성찬 핀이 체육관으로
- 3개: 체육관 성찬 옆에 은석 핀이 '띡' 나타남 (히든 설정: 성찬이 은석 폰을 뺏어 위치 공유 등록)
- 4개: 펫캠 '거실 캠 · 사람의 움직임이 감지되었어요' 알림 → 누르면 펫캠 팝업(움짤) + 두 사람 핀이 같이 '집'으로

※ 미션 진행은 새로고침하면 처음으로 돌아가요.

### 주소 끝에 붙이면 (작업 확인용)
- `#home` : 홈 화면에서 시작 (알림은 바로 시작)
- `#lock` : 잠금화면부터 시작 (암호 `2001`)
- `?v=아무숫자` : 크롬이 예전 파일을 기억하고 있을 때 새로 받게 하기

## 2. GitHub에 올리기

### 파일 구성 (이 구조 그대로여야 해요)
```
index.html        뼈대 (맨 위)
README.md         이 안내서
css/style.css     디자인
js/data.js        ★ 대화·게시글·일정 같은 내용
js/app.js         화면 동작
images/...        사진
```
- `app.js`, `data.js`는 꼭 **js 폴더 안에**, `style.css`는 **css 폴더 안에** 올려야 해요. 맨 위에 올리면 반영이 안 돼요.
- 폴더에 넣을 땐 GitHub에서 **그 폴더에 들어간 다음** Add file → Upload files.
- 올린 뒤 1~2분 기다리고, 크롬은 최대 10분 동안 예전 파일을 쓸 수 있어요. 바로 확인하려면 시크릿 탭이나 주소 끝 `?v=숫자`.
- GitHub 웹 업로드는 파일 하나당 **25MB**까지. 사진·움짤은 5MB 이하 권장.

### 화면이 하얗거나 검게 나오면
- data.js를 고친 뒤라면 따옴표(`'`)나 쉼표(`,`)가 빠졌을 가능성이 커요.
- 오류가 나면 화면에 흰 상자로 '⚠️ 오류'와 원인이 떠요. 캡처해서 확인하세요.

## 3. 내용 고치는 법 (`js/data.js`)

| 바꾸고 싶은 것 | data.js에서 찾을 이름 |
|---|---|
| 상태바·스포티파이 재생 곡, 플레이리스트 | `CONFIG` (`nowPlaying`, `playlist`) |
| 홈 화면 앱 | `HOME_APPS`, `DOCK_APPS` |
| 알림 순서·간격, DM 타이핑 속도 | `BANNERS`, `BANNER_TIMING`, `DM_TYPING` |
| 카톡 대화·프사 | `KAKAO` (`avatars`, `chats`) |
| 에타 게시판·스크랩 글·시간표·광고 | `EVERYTIME` |
| 인스타 피드·댓글·스토리·DM 문구 | `INSTAGRAM` |
| 펫캠 녹화 기록 | `PETCAM` |
| 캘린더 | `CALENDAR_EVENTS`, `CALENDAR_WEEKLY` |
| 사진 앱 (날짜·장소) | `ALBUM` |
| 메모 / 전화 / 문자 / 크롬 / aiAsk | `MEMOS` / `CALLS` / `SMS` / `CHROME` / `AIASK` |
| 지도 위젯 핀 위치 | `MAP_WIDGET` |
| 마지막 펫캠 알림·팝업 | `PETCAM_ALERT` |

### 자주 쓰는 표시
- 카톡 `from: 'me'` = 성찬이 보낸 것, `read: false` = 상대가 안 읽음(노란 1)
- `{ date: '2026-06-03' }` = 날짜 구분선
- 카톡 메시지 `type`: `'photo'`, `'deleted'`(삭제된 메시지), `'file'`, `'call'`, `'vote'`
- 프사 `'default'` = 기본 프사 (카톡: 하늘·파랑·보라 중 하나 / 인스타: 회색)
- 인스타 대댓글: 댓글 안에 `replies: [ { id: '...', text: '...' } ]`
- 펫캠 `blur: true` = 사진 없이 흐린 화면 + 재생 안 됨, `star: true` = 목록에 ★ 표시
- 사진 앱 `place` = 📍장소
- 사진 자리에 `.mp4` 경로를 쓰면 소리 없이 자동 반복 재생돼요. (GIF보다 훨씬 가벼움)

### 독자 댓글
- 인스타 피드 댓글은 **각 독자의 브라우저에만** 저장돼요. 아이디는 ilovegay → zltmgo → … 순서로 붙고 12개 뒤엔 반복돼요.
- 독자끼리 댓글을 공유하려면 `js/app.js` 맨 위 `COMMENTS_API_URL`에 구글 Apps Script 주소를 넣으면 돼요. (코드: `comments-apps-script.gs`)
